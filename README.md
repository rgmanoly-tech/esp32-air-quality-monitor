
# ESP32 Air Quality Monitoring System

## Project Overview

This project focuses on designing and developing a low-cost air quality monitoring system using an ESP32 microcontroller.

The system will eventually collect environmental measurements from multiple sensors, display readings, and store data for further analysis. The project is also intended to explore embedded systems programming, sensor communication protocols, and electronic circuit design.

This project is being developed from scratch as a hands-on learning experience in electrical engineering and embedded systems.

## Project Objectives

- Develop firmware using C++.
- Understand how microcontrollers communicate with sensors.
- Collect and process environmental measurements.
- Display sensor readings on an OLED screen.
- Store collected measurements for later analysis.
- Use Python to analyze and visualize collected data.
- Design a circuit schematic and custom PCB using KiCad.

## Planned Hardware

The following components are planned for the physical prototype:

- ESP32 development board
- Air quality sensor
- Dust/particulate matter sensor
- Temperature and humidity sensor
- OLED display
- MicroSD card module

*Hardware selection and final component specifications are still being determined.*
